# 동림 로고 (확정본)

홈페이지에 쓰는 동림 로고 파일입니다. 글자를 윤곽선(path)으로 바꾼 벡터라 폰트 없이 어디서나 똑같이 보입니다.

| 파일 | 용도 |
|---|---|
| `svg/donglim-horizontal.svg` | 가로형 기본 (홈페이지 헤더, 관리자 화면) |
| `svg/donglim-horizontal-white.svg` | 가로형, 어두운 바탕용 |
| `svg/donglim-stacked.svg` | 세로형 (명함, 간판) |
| `svg/donglim-stacked-white.svg` | 세로형, 어두운 바탕용 (홈페이지 하단) |
| `svg/donglim-en.svg`, `svg/donglim-en-white.svg` | 영문 단독 (해외용, 좁은 자리) |
| `svg/donglim-favicon.svg` | 파비콘 (사이트 최상위 `favicon.svg`와 같음) |
| `png/` | 문서·메신저용 PNG (투명 배경) |
| `donglim-logo-board.pdf`, `.png` | 로고 보드 (형태·바탕색·색·서체 안내) |

## 사용 규칙

- 로고 둘레에는 ‘동’ 한 글자 높이만큼 여백을 두세요.
- 비율을 늘리거나 줄이지 말고, 한글과 영문을 다른 색으로 나누지 마세요.
- 대비가 낮은 바탕에는 두지 마세요. 어두운 바탕에는 `-white` 파일을 씁니다.
- 상표 등록 전에는 유사 상표를 확인하세요.

서체: Bricolage Grotesque(영문), Gothic A1(한글). 모두 SIL Open Font License(상업적 사용 가능)입니다.
